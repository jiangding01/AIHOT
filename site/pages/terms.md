页首说明：

> VibeDaily（vibe.jiangding.me）汇集 AI 编程领域的公开信源，由模型生成中文标题、摘要和推荐理由，原文版权归各来源所有。网页、RSS、公开 API 与 MCP 均可匿名使用；个人与非商业用途无需申请，商业用途请先联系我们。

## 1. 本站提供什么

VibeDaily 是一个面向开发者的 AI 编程资讯站。我们从公开的官方博客、更新日志、媒体、个人博客和社交账号收集资料，由大语言模型完成相关性筛选、评分、中文标题与摘要、推荐理由和事件归组，每天编出一份日报，每周、每月汇编周报和月报。

页面上的“AI 评分”是模型对一条资料值得关注程度的估计，只用于排序和精选，不代表对产品、公司或观点的评价或推荐。

## 2. 内容的准确性

标题、摘要、推荐理由、评分和日报都由模型生成，可能遗漏、误读或出错。重要信息请以原文为准，每条内容都附有原文链接。本站内容不构成技术选型、采购、投资或其他决策的建议。

发现内容有误，欢迎通过[反馈页](/feedback)告诉我们。

## 3. 原文版权与来源方的权利

原文的版权归各来源所有。本站默认只展示标题、摘要和原文链接；只有来源明确允许时，才在站内展示全文。

如果你是来源方，希望更正、下架或调整展示方式（例如只保留链接），请通过[反馈页](/feedback)联系我们，并说明涉及的页面地址。我们会尽快处理。

## 4. 你可以怎样使用本站的内容

这里说的“本站内容”，是指本站自己生成的部分：中文标题与摘要、推荐理由、精选与排序、事件归组、日报、周报和月报。原文本身的使用，适用其原来源的规则。

**可以直接使用，无需申请：**

- 个人阅读、学习和研究；
- 在非商业场合引用或分享本站内容，请注明“来源：VibeDaily”并附上本站或原文链接；
- 用 RSS、公开 API 或 MCP 为自己或团队内部订阅、查询本站内容，包括接入自己的 AI 助手或 Agent。

**需要事先联系我们并取得同意：**

- 在商业产品、付费服务或商业推广中使用本站内容；
- 批量抓取、镜像、转载或再分发本站内容，或把本站内容整理成数据集对外提供；
- 用本站内容训练或评测对外提供的模型；
- 去掉来源标注后转载。

**不允许：**

- 冒充本站或来源方发布内容，或暗示本站为你的产品背书；
- 绕过访问频率限制，或以影响本站正常运行的方式访问。

## 5. 接口与访问频率

RSS、公开 API 和 MCP 都是匿名只读接口，接入方式见 [Agent 接入页](/agent)。请按响应中的缓存时间（`Cache-Control`）轮询，不要并发重试；收到 429 时请等待 `Retry-After` 指定的时间。写程序访问时，请在 User-Agent 中写明你的应用名称。

对于明显影响本站运行的访问，我们可能不经通知直接限流或封禁。

## 6. 服务的变化

本站是个人运营的项目，按“现状”提供，不保证内容完整、及时，也不保证服务持续可用。我们可能调整信源、功能和接口，必要时也可能暂停或停止服务；影响接口使用者的变化会尽量提前在[更新日志](/changelog)中说明。

在法律允许的范围内，本站不对因使用或无法使用本站内容造成的损失承担责任。

## 7. 规则的更新

本规则可能更新。更新后会修改页首的版本号和生效日期，重要变化会在[更新日志](/changelog)中说明。更新后继续使用本站，即表示你接受更新后的规则。
