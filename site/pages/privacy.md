页首说明：

> 使用 VibeDaily 不需要注册或登录。本站不放访客统计、广告或第三方追踪代码，不给普通读者设置 Cookie，只处理让网站正常运行和处理反馈所必需的信息，不出售任何个人信息。

## 1. 本站不做的事

- 不需要注册账号，也没有面向读者的登录；
- 不给普通读者设置 Cookie（只有站长登录管理后台时才会使用会话 Cookie）；
- 不加载第三方统计、广告、追踪代码、外部字体或公共 CDN；
- 网站程序不保存你搜索的关键词，自己的日志也不记录访问地址里的参数（但站内搜索的关键词会出现在服务器访问日志记录的页面地址里，见第 4 节）。

## 2. 保存在你浏览器里的数据

收藏、已读记录、深浅色和字体设置、最近搜索（你搜过的词，最多 10 条）、更新日志的已读状态和反馈草稿，保存在你当前的浏览器里；返回时的列表位置、滚动位置和展开状态只存在当前标签页的会话存储里，关闭标签页即清除。

这些数据都不会发送到服务器。清除浏览器数据后它们会消失，换设备也不会同步。收藏、已读记录和外观设置可以在“收藏”页导出和导入。

## 3. 你提交的反馈

你在[反馈页](/feedback)提交的内容、选填的邮箱、提交时所在页面的地址，以及你选择附上的截图，会保存在本站服务器上，只用于处理你的反馈，以及在你留了邮箱时回复你。这些资料不会转发给第三方。

为了防止滥用，服务器会保存一个由网络地址和浏览器类别经密钥加密散列得到的标识，不保存原始的网络地址。这个标识只用于限制提交频率和封禁滥用来源。

反馈资料会一直保存，直到站长处理后删除。你可以随时通过反馈页要求查询或删除你提交过的反馈，请说明大致的提交时间和内容，方便我们找到它。

## 4. 服务器访问日志

本站运行在一台海外云服务器上，由 Nginx 接收访问。Nginx 会按惯例记录访问日志，内容包括访问者的 IP 地址、访问时间、访问的页面地址（包括地址里的参数，例如站内搜索的关键词）、来源页面和浏览器信息。这些日志只保存在这台服务器上，用于排查故障和防范攻击，每天轮换一次，**52 天后自动删除**。

网站程序自己的日志只记录请求方式和页面路径，不记录 IP 地址和访问地址里的参数。

本站的域名解析由 Cloudflare 提供，目前访问不经过 Cloudflare 的代理或 CDN。今后如果启用，会在这里更新说明。

## 5. 第三方内容

本站展示的是第三方原文的标题、摘要和链接。原文中的图片由本站服务器代为加载，你的浏览器不会因此直接访问来源网站；视频则由你的浏览器直接从原网站加载：播放器设为不预加载、不自动播放，通常在你点击播放后才开始读取，但个别浏览器可能提前请求少量信息。

点击原文链接后，你访问的是对方网站，适用对方的隐私政策。

## 6. 公开接口

通过 RSS、公开 API 或 MCP 访问本站时，和访问网页一样，只会在上面第 4 节所说的服务器访问日志中留下记录。

## 7. 联系与更新

关于隐私的问题，或希望查询、删除你提交过的反馈，请通过[反馈页](/feedback)联系我们。

本说明可能更新。更新后会修改页首的版本号和生效日期，重要变化会在[更新日志](/changelog)中说明。
